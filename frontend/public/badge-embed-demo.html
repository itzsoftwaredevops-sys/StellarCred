StellarCred Badge Embedding Demo

The StellarCred verification badge is designed to be embedded in third-party sites via iframe. This page demonstrates various embedding configurations and theme options.

Dark Theme Badge

Badge on a light background with dark theme:

<iframe src="/badge?wallet=GTEST&claim=kyc&theme=dark" width="320" height="80" ></iframe>

Light Theme Badge

Badge on a dark background with light theme:

<iframe src="/badge?wallet=GTEST&claim=kyc&theme=light" width="320" height="80" ></iframe>

Compact Mode

Smaller badge suitable for sidebars and constrained layouts:

<iframe src="/badge?wallet=GTEST&claim=kyc&theme=dark&compact=1" width="260" height="60" ></iframe>

Query Parameters

The badge accepts the following URL parameters:

  • wallet (required) — Stellar wallet address to verify
  • claim or type (required) — Credential type (kyc, age, income, jurisdiction, funds, accreditation, employment)
  • theme (optional) — "light", "dark", or "auto" (default: dark)
  • compact (optional) — "1" or "true" for compact layout
Note: The badge reads verification status from the Soroban blockchain in real-time. Network unavailability is displayed as "Unknown" rather than "Not verified" to avoid misleading embeds during outages.

Security & Framing Policy

Only the /badge route is frameable. All other StellarCred routes (holder, issuer, verify, etc.) deny framing via X-Frame-Options: DENY and frame-ancestors 'none'.

Operators can optionally restrict which origins may embed the badge by setting the BADGE_ALLOWED_ORIGINS environment variable to a comma-separated list of allowed domains. When unset, the badge is frameable by any origin.

# Allow only specific domains to embed the badge BADGE_ALLOWED_ORIGINS=https://example.com,https://partner.org
